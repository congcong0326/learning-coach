# PRD：题库与本地登录极简版

## 1. 文档目的

本文档只描述当前产品需求：产品为谁解决什么问题、用户如何完成核心流程、当前交付什么、不做什么。

技术架构、数据库、Docker 和命令契约分别见 `docs/architecture/` 与 `docs/dev-setup.md`。

## 2. 产品一句话

当前产品是一个本地优先的算法题库浏览应用，提供本地注册登录、题库列表和题面详情查看。

## 3. 目标用户

- 需要在本地浏览算法题库的个人用户。
- 需要一个可继续扩展的全栈题库基座的开发者。

## 4. 核心流程

```text
注册或登录
-> 进入题库列表
-> 按分页浏览题目
-> 打开题目详情
-> 查看中文题面、标签、难度和 LeetCode 链接
```

后端另提供一个题库问答 Agent loop 实验入口，用于验证模型通过受限题库工具查询题库并回答问题。该入口当前不对应前端页面。

## 5. 核心页面

### 5.1 登录与注册

提供本地账号能力。用户注册或登录成功后，后端设置 HttpOnly session cookie，前端进入题库页。

### 5.2 题库列表页

展示题目列表，包含题号、标题、中文标题、难度、标签和分类。列表支持分页，数据来自后端 `GET /api/problems`。

### 5.3 题面详情页

展示单题详情，包含题号、中文标题、英文标题、难度、标签、分类、题面 Markdown 和 LeetCode 外链。数据来自后端 `GET /api/problems/{slug}`。

## 6. 当前范围

当前必须保留：

- 本地用户注册登录。
- HttpOnly session cookie 登录态。
- 后端健康检查和数据库健康检查。
- 题库 seed 准备、导入、查询。
- 题库列表和题面详情页面。
- 后端最小题库问答 Agent loop 实验入口。
- Docker Compose、Makefile 和 smoke test 基础工作流。

当前不做：

- 模型 API 资产管理页面。
- LLM Run 持久化、完整 AI 教练、提示词管理和 AI eval。
- 目标校准、学习计划、训练工作台、代码 review、提交反馈和复盘。
- 用户画像、下一题推荐、学习仪表盘、RAG、Trace。
- 本地代码运行、在线判题、自动提交 LeetCode。

## 7. 成功标准

- 新用户可以注册、登录、退出登录。
- 未登录用户访问应用会被引导到登录页。
- 已登录用户默认进入题库页。
- 题库列表可分页展示静态题目字段。
- 用户可以打开题面详情并看到中文题面内容。
- 已登录用户可以调用后端题库问答 Agent loop，未登录用户会被拒绝。
- 基础后端测试、前端测试、lint/type/build 和 Compose 配置验证通过。

## 8. 后续恢复池

如需恢复 AI 教练或训练闭环，必须先新增当前版本 PRD 或设计文档，再实施。不能把已删除的旧实现或旧文档当作当前事实。
