# PRD：面向 AI 教练决策的用户画像

## 1. 文档目的

本文档定义当前 MVP 中用户画像的产品用途和边界。画像服务于 AI 教练决策，不是独立的数据看板。

## 2. 产品定位

用户画像用于回答三个问题：

- 用户当前更需要入门引导、独立训练还是冲刺式追问。
- 用户在哪些能力维度上反复出错。
- 下一题或下一轮训练应该补什么。

当前画像主要在后端生成、合并和提供给 AI 教练，不做完整可视化仪表盘。

## 3. 核心原则

### 决策优先

画像字段必须能影响教练动作、提示档位、代码 review 或下一题建议。不能只为了“看起来完整”堆字段。

### 事实和结论分离

训练事实来自用户输入、代码尝试、提交反馈、AC 动作和复盘。画像结论是基于这些事实的摘要，不能替代事实本身。

### 增量更新

每道题完成后生成画像增量，再合并为新的画像快照。增量需要能追溯到具体训练会话和复盘证据。

### 安全输入

给模型的画像摘要必须是脱敏、压缩后的决策上下文，不包含完整用户输入、完整代码、API key、session token 或完整题解。

## 4. 画像输入来源

当前 MVP 输入来源：

- 目标校准：当前水平、目标、时间线、投入时间、默认训练语言、自评弱项。
- 训练过程：教练阶段、用户卡点、提示档位、代码尝试、提交反馈。
- AC 结果：是否通过、通过前经历的主要失败类型。
- 单题复盘：主要问题、掌握点、复杂度、下一步建议。

不作为当前输入来源：

- 全站行为埋点。
- 第三方平台自动抓取。
- 完整 LeetCode 历史。
- RAG 检索 trace。

## 5. 画像核心结构

当前画像至少覆盖：

- 当前训练水平：入门、进阶、冲刺等粗粒度判断。
- 默认训练语言。
- 能力维度：题意理解、暴力建模、优化能力、复杂度分析、边界条件、代码实现、调试能力、表达能力。
- 题型掌握度：数组、哈希、双指针、滑动窗口、栈队列、二分、树、图、动态规划等可逐步扩展。
- 教练策略建议：起手提问方式、提示节奏、是否更强调边界或复杂度。
- 近期弱项：从最近训练事实中提取的少量高信号问题。

字段不要求一次性完整，但新增字段必须说明它会影响哪个教练决策。

## 6. 画像更新流程

### 初始画像

用户完成目标校准并确认学习计划时，系统可根据目标校准信息生成初始画像快照。

### 单题训练中

训练中记录事实，不频繁改写长期画像。可以把当前会话事实作为教练上下文的一部分，用于当轮判断。

### 单题 AC 后

生成单题复盘时，同时生成画像增量：

- 本题暴露的能力变化。
- 证据摘要。
- 置信度。
- 下一步训练建议。

### 合并

后端负责把画像增量合并成新的画像快照。合并时应保留长期趋势，不因单题表现直接大幅覆盖结论。

## 7. LLM 与后端职责边界

LLM 可以：

- 根据训练事实提出画像增量建议。
- 总结卡点和证据。
- 给出下一步训练建议。

后端必须：

- 校验结构化输出。
- 控制字段范围和取值。
- 关联训练会话、复盘和画像增量。
- 生成安全的画像摘要供教练使用。
- 避免把完整敏感内容写入画像。

不允许：

- 让 LLM 直接覆盖长期画像快照。
- 在画像里保存完整用户代码或完整聊天记录。
- 用没有证据的标签长期影响用户。

## 8. 画像如何驱动教练

个性化第一问：

- 入门用户：先确认题意和暴力思路。
- 熟练用户：直接追问复杂度、不变量或边界条件。
- 近期边界错误多的用户：优先要求列边界用例。

提示档位：

- 画像显示用户容易直接依赖答案时，降低提示升级速度。
- 连续同类卡点出现时，可以更快给方向档或关键档，但仍不能直接给完整答案。

代码 review：

- 近期实现错误多时，优先检查循环边界、状态更新和初始化。
- 近期复杂度判断弱时，review 后补充复杂度追问。

下一题建议：

- 优先结合当前计划顺序、题型覆盖、难度和近期弱项。
- 当前 MVP 先使用规则化建议，不做复杂推荐算法。

## 9. 用户可见性

当前 MVP 的画像主要通过单题复盘间接展示：

- 本题暴露了什么问题。
- 画像发生了什么变化。
- 下一题为什么这样推荐。

暂不做独立画像仪表盘和完整画像编辑器。

## 10. MVP 范围

当前必须完成：

- 初始画像或安全画像摘要。
- 单题复盘产生画像增量。
- 画像快照版本化。
- 教练读取安全画像摘要。
- 下一题建议使用画像信号。

当前可以简化：

- 能力维度先粗粒度。
- 题型掌握度先覆盖常见题型。
- 画像合并先使用保守规则。

当前不做：

- 独立学习仪表盘。
- 用户手动编辑完整画像。
- 画像驱动计划补强入口。
- 复杂推荐算法。
- 第三方刷题历史自动导入。

## 11. 成功标准

- 单题 AC 后能生成与训练事实相关的画像增量。
- 下一题建议能解释使用了哪些训练信号。
- 教练第一问和提示策略能体现用户水平或近期弱项。
- 画像摘要不包含敏感信息、完整代码或完整聊天记录。
