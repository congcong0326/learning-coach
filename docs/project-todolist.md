## 后续恢复池

这些能力已移出当前项目。恢复时必须先新增当前版本 PRD 或设计文档，不能直接按旧实现恢复。

| 能力 | 优先级 | 状态 | 恢复条件 |
| --- | --- | --- | --- |
| 题库筛选和搜索增强 | P1 | 未开始 | 题库列表基础体验稳定后设计筛选交互 |
| 题单或收藏 | P1 | 未开始 | 明确用户需要持久化哪些个人题库数据 |
| AI 教练和学习计划 | P2 | 暂停 | 基于最小题库 Agent loop 重新定义产品闭环、模型资产、安全边界和数据模型 |
| 训练工作台和复盘 | P2 | 暂停 | AI 教练重新立项后再设计 |
| 用户画像和推荐 | P2 | 暂停 | 有稳定训练事实来源后再设计 |
| RAG、Trace 和 eval | P3 | 暂停 | AI 能力恢复后按调试和质量需求设计 |
| 本地 code-runner | P3 | 暂停 | 明确隔离容器、输入协议、超时控制和安全策略 |
